## Definitions

- **Matched:** The file in `src/<section>/`, built with the compiler flags recorded in `symbols/<section>.json`,
  reproduces the original bytes at the function's address.
  - For the LEON processors, `tools/diff.py` first compares the instruction shapes. `tools/exact.py` then links the
    object at its real address and requires identical bytes.
  - For the 8051, `tools/diff8051.py` compares the Keil object byte for byte, except for the bytes the linker fills in.
- **Library functions:** Routines recognised byte for byte in the toolchains' own libraries (`tools/libmatch.py`,
  `tools/keillib.py`) count as matched. They are recorded as `.lib` entries.
- **Function counts:** These come from Ghidra's function table (`symbols/<section>.functions.json`), corrected with
  `tools/splits.py` and `tools/mergetails.py`. In 8051 bank 3, most of the 1,205 entries are table bytes that the
  import marked as code; that bank is mostly data.

## Verification

`python3 -I tools/verify.py leon2m leon2s 8051_bank0 8051_bank1 8051_bank2` rebuilds every matched function and
compares it with the firmware. The entries below are not confirmed by that script; each is checked another way.

| Entry | How it is checked |
|---|---|
| `FUN_a0153c74` | The shape comparison in `tools/diff.py` reports a difference, but a raw word comparison (`tools/check/rawcmp.py`) finds 0 of 350 words different. |
| Start-up code of 8051 banks 0 and 2 (`FUN_CODE_13f7`, `FUN_CODE_d426` and their reset jumps) | Rebuilt from Keil's `STARTUP.A51` and `INIT.A51` with `tools/startup8051.py`. |
| `8051_bank0 FUN_CODE_123a`, `FUN_CODE_1249`, `8051_bank2 FUN_CODE_da66`, `FUN_CODE_da86` | Keil entry code generated by the file that calls it (`FUN_CODE_0c83.c`, `FUN_CODE_0003.c`), and checked together with that file. |
| `8051_bank0 FUN_CODE_7400`, `FUN_CODE_7527`, `FUN_CODE_7f9d` | Not code: zero padding inside the slot area, recorded as data. |
| `8051_bank2 FUN_CODE_cee9` | Built with the LX51 linker's code packing and checked with `tools/lx51judge.py`. |
