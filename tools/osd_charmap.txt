# A character is given only where the glyph's picture shows it. Where one picture fits more than one character
# (ニ and 二, ベ and べ, 一 and ー, I and l, Latin and Cyrillic letters of the same shape, the apostrophe ’ of
# font 0xF7), the texts that use the code decide. Where two codes of one font have the same picture and the same
# use, only one of them gets the character. Codes 0xF0..0xFE switch the font and are never characters.
# Glyphs that show more than one character (syllables of Thai, Devanagari, Bengali and the Arabic script,
# and the letters of Hebrew with vowel points) have no character here.
